사이트 운영 및 정보 수집

NyanPunch는 개인 개발 블로그입니다. 회원가입, 댓글, 문의 양식을 운영하지 않으며, 방문자의 개인정보를 별도로 수집하는 분석 도구를 사용하지 않습니다.

호스팅

이 사이트는 GitHub Pages에서 제공됩니다. GitHub는 서비스 운영 및 보안 목적으로 방문자의 IP 주소 등 기술 정보를 처리할 수 있습니다. 자세한 사항은 GitHub 개인정보처리방침을 확인해 주세요.

브라우저 저장소

선택한 화면 테마를 유지하기 위해 브라우저의 로컬 저장소에 테마 설정을 저장합니다. 이 정보는 서버로 전송되지 않으며, 브라우저 설정에서 삭제할 수 있습니다.

광고

현재 Google AdSense 광고와 광고 쿠키를 사용하지 않습니다. 광고 또는 분석 서비스를 도입할 경우, 적용 전에 이 방침을 수정하고 필요한 동의 절차를 마련합니다.

외부 링크와 이메일

외부 링크를 열면 해당 서비스의 개인정보처리방침이 적용됩니다. 이메일로 문의하면 회신에 필요한 이메일 주소와 문의 내용이 이메일 서비스에 저장될 수 있습니다. 문의에 불필요한 민감한 정보는 보내지 마세요.
